# cc-work-log

Claude Code のエージェントとサブエージェント(Claude が作業を分担させる子のエージェント)が、
いま何をしているかを日本語の短い文でペインに流す mod です。
任せた作業を横目で追い、「何を読んで、何を編集して、何を実行したか」を把握しやすくします。

## できること

- **`/cc-work-log`** でペインを開きます
- ツールを呼ぶたびに1行増えます。実行中は `…`、成功は `✓`、失敗は `✗`
  - `src/a.ts` を読む / `src/a.ts` を編集 / `src/a.ts` を書き込む
  - Bash はコマンドの説明(`description`)を出します。説明が無いか日本語でなければ、コマンドの先頭を出します
  - サブエージェント #1 Explore·haiku-5-5『テストを調べる』を起動
  - 決まった言い回しの無いツールは「〇〇 を使う」、MCP のツールは「MCP 〇〇 の △△ を呼ぶ」
- ペインの先頭に、メインのエージェントが使っているモデル(`/model` で選んだもの)を出します
- サブエージェントの作業は、行の頭に `↳ #<番号> <種類>·<モデル>`(例 `↳ #1 Explore·haiku-5-5`)を付けて区別します。番号はセッションの中で起動した順です
- サブエージェントが報告を返す内部の仕組み(`SubagentHandback`)は出しません
- ターンが終わると、区切りの行(回答した / 中断された / エラーで終わった と所要時間)を出します
- 残すのは直近 50 件です。ログはセッションの中だけで持ち、ファイルに保存したり外部に送ったりはしません

ツールの呼び出しを止めたり書き換えたりはしません。見るだけです。

## 見せ方: 一覧とツリー

ペインの左上のボタン(ペインにフォーカスがあるときは `v` キー)で、2つの見せ方を切り替えます。

- **一覧**(初期値): 上のとおり、メインとサブエージェントの作業を時刻順に1列で流します
- **ツリー**: メインのエージェントを根、サブエージェントを枝にして、作業をエージェントごとにまとめます

```
メイン·opus-5-5 …
├─ ✓ `a.ts` を読む
├─ #1 Explore·haiku-5-5『テストを調べる』 ✓ 12秒
│  ├─ ✓ 「TODO」を検索
│  └─ ✓ `test/a.test.ts` を読む
└─ #2 Plan·sonnet-5-5『方針を立てる』 …
   └─ … テストを実行
```

- 枝には `#番号 種類·モデル『説明』` と、状態(実行中 `…` / 終了 `✓` / 失敗 `✗`)、終えたものは所要時間を出します
- サブエージェントがさらにサブエージェントを起動したら、入れ子にします
- ターンごとにメインを根にしたツリーを上から積みます。回答を終えたターンも、入りきるかぎりツリーのまま残し、根に終えた時刻を添えます
- ペインの縦幅が足りないときは、次の順に詰めます。実行中の枝の作業は畳みません
  1. 前のターンの終えた枝の作業を、古いターンから畳む(「作業 n 件を畳んだ」)
  2. 前のターンを、古いものから「回答した(12秒)」の1行に畳む
  3. 今のターンの終えた枝の作業を畳む
  4. 畳んだ前のターン、ツリーの上のほう(古い作業)の順に省く

ペインを開いたときの見せ方は、`/config` の `view`(`list` / `tree`、初期値 `list`)で決めます。ボタンで切り替えたものは、そのセッションのあいだ保たれます。

## ターンごとの要約(任意)

ターンの終わりに、そのターンの作業をモデルで1〜2行に要約して出せます。初期値はオフです。
`/config` の、この mod の項目で設定します。

| 項目 | 値 |
| --- | --- |
| `summaryModel` | `off`(初期値) / `haiku` / `sonnet` / `opus` / `custom` |
| `summaryModelCustom` | `custom` を選んだときに使うモデル ID や略称 |

- 要約にはプランの使用量を使います。`sonnet` や `opus` は消費が多めです
- モデルが無い・組織が許可していないなど、直らない理由で失敗したときは、ペインに理由を出してそのモデルでの要約を止めます。設定を変えると再開します
- 混雑などの一時的な失敗は、その回だけ「要約できませんでした」と出し、次のターンでまた試します

## ペインの位置

ペインが右側に出るのは、全画面表示のレイアウトで端末の幅が 110 列以上あるときだけです。
それ以外(通常の画面や tmux)では、プロンプトの上に挟まる形で出ます。これは Claude Code 側の仕様です。

## インストール

```
/plugin install cc-work-log --marketplace lu-llc-jp/lu-claude-mods
```
