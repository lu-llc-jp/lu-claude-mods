# cc-skill-map

Claude Code を起動したディレクトリで使えるスキル(`/name` で呼べる、手順を書いた指示書)を一覧にし、
選んだスキルの手順の流れをペインに図で出す mod です。
スキルが何をして、どこで人の承認を待ち、どのサブエージェント(Claude が作業を分担させる子のエージェント)に任せ、何を残すのかを、
SKILL.md を読み返さずに把握できるようにします。

## できること

- **`/cc-skill-map`** でペインを開き、セッションで使えるスキルを出どころ(プロジェクト・ユーザー・プラグイン・同期・組み込み)ごとに並べます
  - そのスキルをサブエージェントに持たせていれば(エージェント定義の frontmatter の `skills:`)、`← エージェント名` を添えます
  - SKILL.md の `description` を薄く添えます
- スキル名を押すと、そのスキルの手順の流れに切り替わります。`/cc-skill-map <スキル名>` で直接開くこともできます

```
╭─ 1 ─────────────────── 人 ─╮
│ メモを受け取る             │
╰──────────────┬─────────────╯
               ▼
╭─ 2 ─────────────────── AI ─╮
│ 整える                     │
│ ▸ 下書き                   │
╰──────────────┬─────────────╯
               ▼
╭─ 3 ─────────────────── 人 ─╮
│ 確かめる                   │
│ ⏸ ここで人の承認を待つ     │
╰──────────────┬─────────────╯
  ↩ 2「整える」へ戻る
               ▼
╭─ 4 ─ サブエージェント re… ─╮
│ 調べる                     │
╰────────────────────────────╯

成果物
▸ 整えたメモ — notes/
```

- 手順を箱にして上から下へつなぎます。箱の右上が担い手で、色でも分けます(AI・人・スクリプト・サブエージェント)
- 人の承認を待つ手順は、枠の色と `⏸` で目立たせます
- 分岐・戻りは、箱の下に `↩ 2「…」へ戻る` / `↪ 5「…」へ進む` と添えます
- 手順が残すものは箱の中に `▸`、スキル全体の成果物は末尾の「成果物」にまとめます
- 流れに出てくるサブエージェントと、そのスキルを持たせているサブエージェントを、流れの上に出します
- `b` で一覧に戻り、`r` で一覧と流れを読み直します

## 流れの読み取り方

SKILL.md は自由に書かれた文書なので、モデルで読み取って流れにします。

- 読み取るのは、スキルを開いたときだけです。結果は、スキルの本文のハッシュと使ったモデルと一緒に保存し(`$.store`。セッションをまたいで残る mod の保存領域)、本文もモデルも変わらないあいだは使い回します。SKILL.md を書き換えると、次に開いたときに読み取り直します
- 読み取りにはプランの使用量を使います。**SKILL.md の本文が、セッションと同じ経路でモデルの API に送られます**
- `/config` の、この mod の項目で、読み取りに使うモデルを選べます

| 項目 | 値 |
| --- | --- |
| `flowModel` | `off` / `haiku`(初期値) / `sonnet` / `opus` / `custom` |
| `flowModelCustom` | `custom` を選んだときに使うモデル ID や略称 |

- `off` にすると、モデルを使わず、SKILL.md の見出し(`##` / `###`)を並べた簡易な流れを出します。担い手・承認・成果物は出ません
- 読み取りに失敗したとき(応答の形が崩れた・API エラーなど)も、理由を添えて見出しの流れで代えます。次に開いたときにまた試します

## SKILL.md の探し方

スキルの一覧は Claude Code のコンテキストの内訳(`/context` と同じもの)から取ります。一覧には SKILL.md の場所が無いので、出どころから探します。

| 出どころ | 探す場所 |
| --- | --- |
| プロジェクト | 起動したディレクトリからホームの手前までの `.claude/skills/<名前>/SKILL.md` |
| ユーザー | 設定フォルダ(`CLAUDE_CONFIG_DIR`、無ければ `~/.claude`)の `skills/<名前>/SKILL.md` |
| プラグイン | インストールしたプラグイン(`plugins/installed_plugins.json`)と、同期されたプラグイン(`plugins/synced/`)の `skills/<名前>/SKILL.md` |
| 同期 | 設定フォルダの `skills/synced/` の下 |
| 組み込み | ファイルが無いので、そのセッションで一度呼ばれたときの本文を使います。呼ばれるまでは理由だけを出します |

サブエージェントとの対応は、設定フォルダとプロジェクトの `agents/*.md` の frontmatter の `skills:` から取ります。

SKILL.md とエージェント定義は読むだけで、書き換えません。

## やらないこと

- 実行中のスキルが今どの手順にいるかは追いません
- MCP など、置き場の分からないスキルは名前だけを出します

## インストール

```
/plugin install cc-skill-map --marketplace lu-llc-jp/lu-claude-mods
```
